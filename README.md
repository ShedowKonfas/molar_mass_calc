# Калькулятор молярной массы и массовых долей

Этот скрипт на Python позволяет быстро рассчитать **молярную массу** (молекулярную массу) любого химического соединения по его формуле, а также выводит **массовые доли** всех элементов с детальным указанием атомных масс, количества атомов и их вклада в общую массу.

## Возможности

- Поддержка всех химических элементов (с атомными массами из стандартной таблицы).
- Распознавание формул с **одно- и двухбуквенными символами** (например, H, Na, Fe).
- Обработка **индексов** (цифр после элемента или скобки), в том числе индексов 1 (опускаются).
- Поддержка **круглых () и квадратных [] скобок**.
- Поддержка **вложенных скобок** (например, (NH4)2SO4, [Fe(CN)6]).
- Вывод подробной таблицы:
  - символ элемента,
  - количество атомов,
  - атомная масса (г/моль),
  - вклад в общую массу (г/моль),
  - массовая доля (в процентах).
- Возможность запросить детали по конкретному элементу.
- Интерактивный режим с подсказками.

## Установка и запуск

### Требования
- Python 3.6 или выше.
- Стандартная библиотека (модули re, никаких внешних зависимостей).

### Скачивание
Скопируйте код из файла `molar_mass_calc.py` (или создайте файл с этим именем) и вставьте в него полный скрипт, который вы получили ранее.

```bash

Поддерживаемые формулы

    С квадратными скобками: [Fe(CN)6], [Cu(NH3)4]SO4

    Вложенные скобки: (Al2(SO4)3), [Fe(CN)6]4- (заряды игнорируются, но формула обработается как [Fe(CN)6]4 — индекс после скобки)

Ограничения

    Не обрабатывает гидраты (например, CuSO4·5H2O). Для расчёта таких веществ нужно вводить сумму формул, например CuSO4 + 5H2O пока не поддерживается.

    Не поддерживает заряды и ионные формы (например, SO4^2-).

    Все элементы должны присутствовать в словаре атомных масс (большинство элементов от H до Og включены).
